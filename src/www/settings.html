After 30 seconds of no local input, periodically nudge the remote machine so it doesn't sleep or lock. For headless/text-only sessions (e.g. a bare Linux shell), use one of the key-press methods instead of mouse jiggle, since mouse movement has no effect there. "Ctrl tap" resets screen-blanking/screensaver timers but not shell/SSH-level idle timeouts (a lone modifier never reaches the tty); "Arrow tap" resets both, at the small cost of being a real keypress.

About

DezKVM-Go Viewer is a web-based interface for the DezKVM-Go mini KVM over USB device, allowing portable KVM access to remote systems via a simple and intuitive web interface.

It is designed to work seamlessly with the DezKVM-Go hardware, providing features such as video streaming, audio output, and keyboard/mouse input forwarding.
